# График отпусков — плагин для GLPI 11–12

Планирование отпусков сотрудников с учётом производственного календаря РФ.

## Возможности

- **Отпуска** (Инструменты → График отпусков → Отпуска): сотрудник, период, статус
  (запланирован / согласован / отклонён), комментарий. Стандартный поиск GLPI, массовое
  изменение статуса, история изменений.
- **Расчёт дней по ТК РФ (ст. 120):** нерабочие праздничные дни (ст. 112) не входят
  в число календарных дней отпуска и продлевают его. Выходные входят. Для каждого отпуска
  хранятся календарные, праздничные дни, дни отпуска и рабочие дни.
- Длительность можно задать **числом дней**: дата окончания считается автоматически с учётом
  праздников. В форме расчёт обновляется сразу, без сохранения.
- Проверка **пересечений** отпусков одного сотрудника.
- **Сводный график:** строки — сотрудники, столбцы — дни года (или выбранных месяцев).
  Выходные, праздники и переносы подсвечены. Фильтр по группе показывает всех её участников,
  поэтому отпуска можно планировать для нескольких человек сразу: щелчок по свободной клетке
  создаёт отпуск с этой даты. Нижняя строка показывает, сколько людей отсутствует в каждый день;
  при превышении заданного порога клетка подсвечивается. Есть выгрузка в CSV.
- **Выгрузка в Excel по форме графика отпусков** (кнопка «Excel» на сводном графике):
  №, сотрудник, должность, все периоды отпуска за год в одной ячейке
  («с 01.05.2027 по 14.05.2027 (14 дн.)», каждый с новой строки), итог календарных дней.
  Строка отдела — название выбранной группы. Если группа не выбрана, выгружаются все группы
  отдельными блоками (только те, где за год есть отпуска). Сотрудник попадает в выгрузку один раз:
  в свою группу по умолчанию, иначе в первую по алфавиту. Сотрудники с отпусками без группы
  идут блоком «Без группы». Выгружается весь год, без отклонённых отпусков.
  ФИО берётся из полей «Фамилия» и «Имя» пользователя, должность — из поля «Должность»
  (справочник «Должности пользователей»).
- **Производственный календарь** на любой год:
  - загрузка с [xmlcalendar.ru](https://xmlcalendar.ru): праздники, переносы выходных,
    сокращённые предпраздничные дни;
  - импорт того же JSON вручную, если у сервера GLPI нет доступа в интернет;
  - быстрое заполнение праздниками по ст. 112 ТК РФ (без переносов);
  - ручная правка любого дня щелчком по календарю;
  - число рабочих дней по месяцам и норма часов (40/36/24 ч).

  После изменения календаря дни в отпусках за этот год пересчитываются автоматически.
- Вкладка **«Отпуска»** в карточке пользователя с итогами по годам.
- Права в профиле (вкладка «График отпусков»): отпуска (чтение/создание/изменение/удаление)
  и календарь (чтение/изменение).

## Установка

1. Скачайте плагин в `glpi/plugins/vacation` (имя папки должно быть именно `vacation`):
   `git clone https://github.com/darksirduk/glpi-plugin-vacation.git /var/www/glpi/plugins/vacation`
   (или распакуйте архив релиза), затем `chown -R www-data:www-data /var/www/glpi/plugins/vacation`.
2. Откройте «Настройки → Плагины» и нажмите «Установить», затем «Включить».
3. Профили с правом изменения настроек получат полный доступ автоматически. Остальным профилям
   выдайте права на вкладке профиля «График отпусков».
4. Откройте «Инструменты → График отпусков → Производственный календарь» и загрузите
   календарь на нужный год.

Требования: GLPI 11.0–12.0.x, PHP 8.2+ (проверено на GLPI 12.0.0, PHP 8.4).
Установка из консоли: `php bin/console plugin:install --username=<админ> vacation`,
затем `php bin/console plugin:activate vacation`. Для загрузки календаря серверу нужен доступ к
xmlcalendar.ru (учитываются настройки прокси GLPI). Без него используйте импорт JSON.

## Как считаются дни

| Тип дня | В отпуск входит | Рабочий |
|---|---|---|
| Пн–Пт | да | да |
| Сб–Вс | да | нет |
| Праздничный (ст. 112) | **нет** | нет |
| Выходной (перенос) | да | нет |
| Рабочий (перенос на Сб/Вс) | да | да |
| Сокращённый предпраздничный | да | да |

## Структура

```
vacation/
├── setup.php, hook.php          — регистрация, установка/удаление
├── inc/vacation.class.php       — отпуск (форма, поиск, расчёт, вкладка пользователя)
├── inc/calendarday.class.php    — производственный календарь
├── inc/schedule.class.php       — сводный график, CSV и Excel (PhpSpreadsheet из состава GLPI)
├── inc/menu.class.php           — меню «Инструменты»
├── inc/profile.class.php        — права в профиле
├── front/*.php                  — страницы
└── public/css/vacation.css      — статика (в GLPI 11+ отдаётся только из public/)
```
